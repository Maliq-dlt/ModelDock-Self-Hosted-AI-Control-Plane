# Support

## Bug

Open a bug issue with:

- ModelDock version and commit;
- OS, Python, Node.js, Docker, and Kubernetes versions;
- sanitized reproduction;
- exact command and error;
- relevant logs without secret or prompt payload.

## Security

Do not open public issues for vulnerabilities. Use GitHub Security Advisories. See `SECURITY.md`.

## Feature

Explain user problem, expected behavior, compatibility impact, and acceptance test.
